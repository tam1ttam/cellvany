Usage

Live Chat Widget

Widget nổi ở góc dưới bên phải. Click nút Hỗ trợ để mở popover. Click link Facebook để mở inbox. Widget tự động đóng khi click ra ngoài.

<script src="live-chat-widget.js"></script>
<script>ChatWidget.init({ facebookUrl: '...' })</script>
Config

Tùy chỉnh nhanh

Truyền facebookUrl để đổi link Fanpage. Các màu sắc và text chỉnh trực tiếp trong file CSS/JS.

ChatWidget.init({
  facebookUrl: 'https://m.me/your-page'
})
